# 실기 점검표 (사용자가 직접 수행)

실제 로봇을 움직이는 시험은 사용자가 한다. 가짜 로봇 시험을 통과했다고 실기에서도 검증된 것은 아니다. 각 항목에 날짜·결과·메모를 적는다. 버튼 이름은 v2 화면 기준이다(2026-11-15).

**준비**
- 흑갈리와 PuppyPi 를 **같은 Wi-Fi** 에 연결하고, 로봇에서 팀 ROS 2 스택(UDP 5001/5002, rosbridge 9090, 카메라 8080, 8090)이 실행 중인지 확인한다.
- 로봇 주변 1 m 를 비운다. 처음에는 연결·설정 화면의 "최고 속도 비율" 을 0.3 으로 낮춘다.
- 기록: 흑갈리 화면은 F12(`shots\ui_*.bmp`) 또는 Xbox Game Bar 녹화(Win+Alt+R), 로봇은 휴대폰으로 찍는다. 시험이 끝나면 exe 옆 `app_log.txt` 도 남긴다.
