# 실기 점검표 (사용자가 직접 수행)

실제 로봇을 움직이는 시험은 사용자가 한다. 가짜 로봇 시험을 통과했다고 실기에서도 검증된 것은 아니다. 각 항목에 날짜·결과·메모를 적는다. "로그 확인"은 사용자가 실기를 하고, 그때의 앱 로그(`app_log.txt`)에 결과가 남은 항목이다. 버튼 이름은 v2 화면 기준이다(2026-11-15).

**준비**
- 흑갈리와 PuppyPi 를 **같은 Wi-Fi** 에 연결하고, 로봇에서 팀 ROS 2 스택(UDP 5001/5002, rosbridge 9090, 카메라 8080, 8090)이 실행 중인지 확인한다.
- 로봇 주변 1 m 를 비운다. 처음에는 연결·설정 화면의 "최고 속도 비율" 을 0.3 으로 낮춘다.
- 기록: 흑갈리 화면은 F12(`shots\ui_*.bmp`, IP 는 가려서 저장) 또는 Xbox Game Bar 녹화(Win+Alt+R), 로봇은 휴대폰으로 찍는다. 수치는 exe 옆 `app_log.txt` 의 `perf` 줄(5 초마다 RTT·유실·카메라)에서 뽑으니 지우지 않는다. 전원 연결 여부도 적는다.
